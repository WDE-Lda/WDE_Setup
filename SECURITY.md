# Security Policy

## Supported Versions

WDE_Setup has no releases: `setup.ps1` is run straight from the `main` branch. Only the
current `main` receives security fixes.

## Reporting a Vulnerability

This is a public repository. Do **not** open an issue or pull request describing a
vulnerability. Report it privately to the repository owner (@gitwde) with:

- the affected commit,
- steps to reproduce or a proof of concept,
- the impact you observed or expect.

You will get an acknowledgement within 5 working days. Confirmed issues are fixed on
`main`; you will be told when the fix is merged, or why the report was declined.

## Dependencies

Dependabot alerts and security updates are enabled. Dependency updates are configured in
`.github/dependabot.yml`.
