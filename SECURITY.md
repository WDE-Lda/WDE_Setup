# Security Policy

## Supported Versions

Only the latest version on `main` receives security fixes. Older versions are not patched;
use the latest `setup.ps1`.

## Reporting a Vulnerability

This is a public repository. Do **not** open an issue or pull request describing a
vulnerability. Report it privately with **Report a vulnerability** in the Security tab
of this repository, with:

- the affected version or commit,
- steps to reproduce or a proof of concept,
- the impact you observed or expect.

You will get an acknowledgement within 5 working days. Confirmed issues are fixed in a
new version; you will be told when it ships, or why the report was declined.

## Secrets

This repository holds no secrets. Secret scanning and push protection are enabled.
